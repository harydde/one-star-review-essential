A make.fun entry for **One-Star Review of Something Essential**: one deadpan single-line one-star review, at most 160 characters, of an everyday essential — sleep.

`main.ts` (Node 22, standard library only) writes the review to `/output/entry.txt`:

> Eight hours a night and I still wake up tired. Will use again tonight.

The review is 70 characters: the sharpest true grievance about sleep (it does not actually refresh you), held fully deadpan with no exclamation and no wink, and the sting turns in the last few words — the reviewer is a repeat customer with no choice.
